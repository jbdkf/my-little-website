Photoshop快速抠图小技巧

27 7 月, 2026 admin 3 min read
  • 一、秒杀级技巧（1分钟搞定）
  • 1. 主体一键抠图（适合背景干净的人像/物体）
  • 点击菜单栏 选择 → 主体，PS会自动识别并选中主要物体。
  • 再点击 选择并遮住，用“调整边缘画笔”涂一下头发或毛发边缘，输出带图层蒙版的结果。
  • 技巧：如果抠出边缘有杂色，在“选择并遮住”里把“全局调整”中的移动边缘向左拉（-10%到-20%），收缩边缘去除白边。
  • 2. 纯色背景秒抠（如白底、蓝底图）
  • 用 魔棒工具（W），容差设为32，点一下背景，Delete删除。
  • 容差越大，选取的颜色范围越宽；如果背景有渐变，勾选“连续”选项。
  • 二、半自动抠图（边缘复杂但对比清晰）
  • 3. 钢笔工具（适合边缘锋利的产品、建筑）
  • 选择钢笔工具（P），模式设为“路径”。
  • 沿物体边缘点击锚点，弯曲处按住鼠标拖出贝塞尔手柄。
  • 闭合路径后，按 Ctrl+回车 转选区，Ctrl+J复制抠出。
  • 技巧：锚点越少越平滑，曲线处用2-3个点即可，别点成密密麻麻的“蚂蚁线”。
  • 4. 通道抠图（神技！适合头发丝、半透明物体）
  • 这是对付细碎发丝和婚纱的杀手锏：
  • 打开通道面板，分别看红、绿、蓝三个通道，选黑白对比最强烈的那个（通常选蓝色通道）。
  • 右键复制该通道，按 Ctrl+L 调出色阶，拖动黑白滑块，让背景变白、主体变黑。
  • 用黑色画笔把主体内部涂黑，白色画笔把背景涂白。
  • 按住Ctrl点击复制的通道缩略图载入选区，回到RGB图层，Ctrl+J复制，头发丝就完美抠出来了。
  • 三、终极精细处理（解决白边、杂色问题）
  • 5. 选择并遮住（优化边缘必杀）
  • 任何选区工具做好粗选后，点击顶部 选择并遮住（旧版叫调整边缘）。
  • 核心参数：
    • 视图模式选“叠加”或“黑底”，方便看清边缘。
    • 边缘检测：勾选“智能半径”，半径设为1-5像素。
    • 用 调整边缘画笔 涂抹头发、毛绒等复杂边缘。
    • 输出选择 “新建带有图层蒙版的图层”，方便后续修改。
  • 6. 去白边终极三招（抠完必看）
  • 如果抠出的物体边缘有一圈白边或背景色：
  • 法一（收缩+羽化）：按住Ctrl点击蒙版载入选区，点击 选择 → 修改 → 收缩（收缩1-2像素），再羽化0.5像素，反选后填充黑色（在蒙版上操作）。
  • 法二（净化颜色）：在“选择并遮住”中，把 “净化颜色” 滑块拉到70%-100%，输出到新建图层。
  • 法三（最小值滤镜）：对有白色描边的图层，点击 滤镜 → 其他 → 最小值，半径设1像素，白边会被收缩掉。
  • 四、哪些图不值得抠（一定要避开）
  • 主体和背景颜色完全融合（如白猫在白墙前）——建议直接重拍或换图。
  • 大面积透明纱质且带复杂背景——通道法耗时，不如用蒙版手涂。
  • 五、效率提速组合拳（老手都在用）
  • 快捷键记牢：Ctrl+J复制选区，Ctrl+D取消选区，[和]调整画笔大小。
  • 图层蒙版优于直接删除：蒙版黑色=隐藏，白色=显示，抠错了用白色画笔擦回来，无损操作。
  • 多工具组合：用“主体”做粗选 → “套索”补选漏掉的区域 → “选择并遮住”修边缘 → “蒙版”微调局部。
